# 長青園照護看板

長照機構（養護中心）使用的簡易照護看板，介面為繁體中文，溫暖柔和的配色。

## 功能

- **長者總覽**：每位長者有插畫頭像、目前狀態（休息中／活動中／用餐中／復健中／就醫中／需留意）與目前所在區域
- **區域人數**：一眼看出各區域（寢室、餐廳、活動室、復健室、庭院花園…）目前有哪些長者，點選即可篩選
- **長者資料**：最新生命徵象（血壓、體溫、脈搏、血氧、血糖、呼吸，超出參考範圍以紅色標示）、病史、過敏、用藥、行動能力、飲食、緊急聯絡人
- **記錄移動**：點一下區域按鈕即記錄長者移動時間；可補登指定時間與備註
- **動線查詢**：依姓名、房號、區域、日期查詢長者去過哪些區域，方便照服員尋找長者

## 資料儲存

所有資料只存在使用中裝置的瀏覽器（localStorage），不會上傳到任何伺服器。畫面上的長者皆為虛構示範資料，可按「重設為示範資料」還原。

生命徵象的參考範圍僅作為畫面提示，不能取代醫療專業判斷。
